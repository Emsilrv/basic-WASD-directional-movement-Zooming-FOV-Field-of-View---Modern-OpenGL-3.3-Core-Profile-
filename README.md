lightweight, real-time 3D rendering engine built in modern C++ and Modern OpenGL (3.3 Core Profile). 
This project demonstrates low-level systems programming, custom memory management, camera math, and GPU shader pipelines.

Key Features :

**FPS Camera Architecture:** 6-DOF camera system featuring WASD navigation, smooth pitch/yaw mouse rotation using trigonometry, and dynamic FOV perspective zoom.
* **Modular Codebase:** Clean separation of camera logic, shader utilities, and buffer wrappers into dedicated `.h` and `.cpp` modules.

Tech Stack & Dependencies

* **Language:** C++
* **Graphics API:** OpenGL 3.3 (Core Profile)
* **Windowing & Input:** [GLFW](https://www.glfw.org/)
* **OpenGL Loader:** [GLAD](https://glad.dav1d.de/)
* **Mathematics:** [GLM](https://github.com/g-truc/glm) (OpenGL Mathematics)
* **Image Loading:** [stb_image](https://github.com/nothings/stb)
